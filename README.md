# To-Do Application

A simple browser-based To-Do application developed as part of an AI-Assistant-Driven SDLC capstone project.

## Features

- Add a To-Do item.
- Delete a To-Do item.
- Save tasks using browser localStorage.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Project Structure

```text
todo-capstone/
├── index.html
├── styles.css
├── app.js
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Add and delete tasks using the application.

Alternatively, open the project in VS Code and use Live Server.

## Project Objective

The application serves as the starting point for demonstrating an AI-driven Software Development Life Cycle using CodeMie assistants, GitHub, Jira, Confluence, and Playwright.

## Testing

Automated testing and test execution reports will be added as part of the capstone workflow.
